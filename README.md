- ✅ تصميم متجاوب (Responsive)

### 🔐 لوحة التحكم
- ✅ موقع منفصل تماماً
- ✅ حماية بكلمة مرور: **433311**
- ✅ إدارة كاملة للمنتجات (إضافة، حذف)
- ✅ إدارة الأقسام

- ✅ حفظ البيانات تلقائياً

## 🚀 كيفية الاستخدام

### 1. فتح الموقع الأساسي
- افتح ملف `index.html` في المتصفح

### 2. الوصول إلى لوحة التحكم
**الطريقة 1: رابط مباشر**
- اذهب إلى `admin-login.html`

**الطريقة 2: من الموقع الأساسي**
- اضغط على أيقونة ⚙️ في أسفل الصفحة (يمين الشاشة)

### 3. تسجيل الدخول
- أدخل كلمة المرور: **433311**
- اضغط "دخول"

### 4. إدارة المنتجات
- **إضافة منتج:**
  1. انتقل إلى تبويب "إدارة المنتجات"
  2. ملء النموذج بالبيانات
  3. اختر صورة (اختياري)
  4. اضغط "إضافة المنتج"

- **حذف منتج:**
  1. ابحث عن المنتج في القائمة
  2. اضغط زر "حذف"

### 5. إدارة الأقسام
- **إضافة قسم:**
  1. انتقل إلى تبويب "إدارة الأقسام"
  2. أدخل اسم القسم والوصف
  3. اضغط "إضافة القسم"

- **حذف قسم:**
  1. ابحث عن القسم في القائمة
  2. اضغط زر "حذف"
